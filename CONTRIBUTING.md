# Contributing to Awesome Arabic Dev

Thank you for your interest in contributing! This list grows because of people like you.

## How to Add a Resource

1. **Fork** this repository
2. **Edit** the `README.md` file
3. Add your resource under the appropriate section
4. Keep the format consistent:
   ```
   - **[Resource Name](URL)** — Brief description in English. وصف مختصر بالعربية
   ```
5. **Submit a Pull Request** with a clear description

## Guidelines

- All resources must be **free or clearly marked as paid**
- Resources should be **primarily in Arabic** or have strong Arabic content
- Descriptions should ideally be **bilingual** (English + Arabic)
- No spam or self-promotion without genuine value
- Keep links working and up to date

## Adding a New Section

If you think a whole new category is needed, open an **issue first** to discuss before adding it.

## Code of Conduct

Be respectful and constructive. We are building a resource for the entire Arab developer community.
