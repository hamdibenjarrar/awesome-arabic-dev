## Why This List? • لماذا هذه القائمة؟

Arabic is the 5th most spoken language in the world with 400M+ speakers, yet the Arabic programming ecosystem is still growing. This list collects the best Arabic-language tech resources in one place.

> Pull requests are welcome! Know a great resource? Open a PR. 🙌

## Arabic NLP / AI Tools

- **[CAMeL Tools](https://github.com/CAMeL-Lab/camel_tools)** — Full Arabic NLP toolkit by NYU Abu Dhabi
- **[AraVec](https://github.com/bakrianoo/aravec)** — Pre-trained Arabic word embeddings
- **[Mishkal](https://github.com/linuxscout/mishkal)** — Arabic text vocalization (تشكيل)
- **[FARASA](https://farasa.qcri.org/)** — Arabic NLP toolkit from Qatar Computing Research
- **[AraBERT](https://github.com/aub-mind/arabert)** — BERT model pre-trained on Arabic text
- **[arabic-reshaper](https://github.com/mpcabd/python-arabic-reshaper)** — Reshape Arabic text for correct rendering

---
- **[toolcraftx](https://toolcraftx.com)** — مجموعة أدوات ذكاء اصطناعي مجانية بالعربية (١٤ أداة: كاتب SEO، مخطط مقالات، توصيف منتجات، سيناريو فيديو، عناوين جذابة، والمزيد). مبنية أصلاً للعربية الفصحى — ليست مترجمة من الإنجليزية. Free Arabic AI toolbox with 14 tools, built natively for MSA Arabic.

## Learning Paths • مسارات التعلم

### 🌱 Beginner (مبتدئ)
1. HTML & CSS → [Elzero Web School](https://elzero.org/study/html-2021-study-plan/)
2. JavaScript → [Elzero JS Bootcamp](https://elzero.org/study/javascript-bootcamp-2021-study-plan/)
3. Git & GitHub basics

### 🚀 Intermediate (متوسط)
1. Choose a framework: React / Vue / Laravel / Django
2. Learn databases: PostgreSQL or MySQL
3. Make your first open source contribution

### 🏆 Advanced (متقدم)
1. System Design & Architecture
2. DevOps: Docker, CI/CD, Kubernetes
3. Cloud: AWS / GCP / Azure
